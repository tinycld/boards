---
title: Card types and custom fields
summary: Giving a board's cards types such as Bug or Feature, with their own fields, pages and rules

order: 22
---

A card type is a form. Every card has one; a new board's cards use the default type, **Card**. To add a type, open **Settings → Forms**, pick **Boards → Card**, and press **New form**. The editor shows the card as users see it: drag fields to move them, add pages, add custom fields (text, number, date, select, people, checklist, files, rich text), and add rules such as "when Severity is High, require Steps". See [Forms and record types](help://core:forms).

To create a card of a type, press **Open full form** in a column's **Add card** composer, or press `c`, to open the full form. Pick the type at the top, and fill the pages. The quick composer still creates a card of the default type.

To change a card's type, open the card's actions menu and choose **Change type**. Values of fields the new type does not have stay stored and come back if the type is changed back.

Custom field values are searchable: text and the names of chosen options show up in search.
